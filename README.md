# Kitchen-cabinet
SolidWorks 3D model and technical drawings of a kitchen cabinet assembly including parts and assembly files and renderings.
## Project Contents
- **CAD_Files/** – SolidWorks part and assembly files  
- **Drawings/** – Engineering drawings exported as PDF  
- **Render_Images/** – Renders showing different views of the cabinet  

## Tools Used
- SolidWorks (Part, Assembly, Drawing)
SolidWorks Visualize (for rendering)

## Features
- Detailed kitchen cabinet with correct proportions  
- Multi-body part/assembly structure  
- Technical drawing with dimensions  
- Smooth, clean rendering for presentation  

## About This Project
This design was created as part of my mechanical modeling practice focusing on structure, assembly methods and realistic presentation.
